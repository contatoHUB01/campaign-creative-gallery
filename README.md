# Campaign Creative Gallery

Crie uma página de relatório para Meta Ads focada na exibição de criativos.

Requisitos:

1. Crie uma lista simulada de anúncios contendo: nome da campanha, título, texto principal (copy), URL de imagem de exemplo, formato (ex: Feed Instagram), cliques, valor gasto e status (Ativo/Pausado).

2. Exiba esses criativos em formato de cards em um grid responsivo.

3. Cada card deve ter a imagem no topo, badge com o status, título em destaque, texto explicativo e uma área inferior com as métricas de cliques e gastos.

4. Utilize Tailwind CSS para um design limpo e moderno, com sombras suaves e cantos arredondados.
